# Modular Drone Frame

## 📋 Project Overview
Lightweight modular drone frame design with carbon fiber components and quick-release mechanisms. This design prioritizes ease of assembly, durability, and weight optimization for extended flight times.

## 🎯 Features
- Modular design for easy maintenance and customization
- Carbon fiber construction for lightweight durability
- Quick-release mechanisms for fast assembly/disassembly
- Optimized weight distribution for stable flight
- Compatible with various motor and ESC configurations

## 📐 Specifications
- **Frame Size**: 450mm wheelbase
- **Weight**: ~350g (frame only)
- **Material**: 3K Carbon Fiber with aluminum connectors
- **Max Takeoff Weight**: 2.5 kg
- **Flight Time**: 25-30 minutes (with standard battery)
